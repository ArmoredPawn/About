                How to play

                Each prompt has lots of right answers. You have 20 seconds to type one.

                • Rarer answers score more. A common answer is worth 10 points; an outlier is worth 100.
                • Wrong answers cost nothing. If yours isn't on the list, try another until time runs out.
                • Your first accepted answer counts, so think before you type the obvious one.
                • Spelling has to be close: capitals, accents, "the" and plurals don't matter.
                Common 10 Familiar 25 Uncommon 50 Rare 75 Outlier 100

                Rarity is set by hand for each answer: how few people would think of it, not how many players typed it.
